# 作品库删除与版本组规则

## 目标
为作品库增加可控的批量删除，区分“删除选中图片”和“删除整个版本组”，避免批量操作误删同组版本。

## 规则
- 默认批量删除只删除用户勾选的图片 ID。
- 版本组删除必须由用户明确触发，删除该用户版本组内的全部图片记录和文件。
- 删除单个版本不会删除同组其他版本；子版本保留，即使源图已删除。
- 所有删除操作按当前用户归属校验，数据库记录和原图/缩略图文件一起清理。
- 画布中引用已删除图片时，服务端保存布局会清理失效节点与连线。
- 批量操作返回成功 ID、失败 ID 和删除数量，前端只清理成功项。

## 界面
- 桌面历史图库和移动图库进入“选择”模式后显示勾选框、已选数量、全选、取消和删除。
- 删除按钮默认执行“删除选中图片”。
- 当选中内容属于版本组时，确认框额外提供“仅删除选中”和“删除整个版本组”两个明确操作；默认聚焦前者。
- 确认文案显示将删除的图片数量和版本组数量。

## 非目标
- 不做回收站、恢复、跨账号删除和后台管理员批量删除。
