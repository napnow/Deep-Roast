# 登录分屏工坊 + 文生图去 Emoji 设计

**日期:** 2026-07-29  
**状态:** 已确认（brainstorming）  
**分支建议:** 当前功能分支或后续 UI 分支均可；仅 UI/文案，不改 API  

## 背景

深焙已完成一版 **Deep Roast Atelier** 全局 token/壳层视觉。用户反馈：

- 登录页仍偏「居中小卡片老后台」，不够新颖  
- 文生图工具栏与风格预设依赖 emoji，与工坊气质不符  
- 跨模式交互（文↔图）有价值，但本轮不实现，只记路线图  

## 目标

1. **登录页**做成有记忆点的「分屏工坊」入口，逻辑与现网一致可跑通  
2. **文生图**去掉工具/预设 emoji，改为文字（或后续可扩展的线标），行为不变  
3. 不引入粒子/重 canvas 动效；不改鉴权、注册规则、联系管理员 API  

## 非目标（本轮）

- 文生文 ↔ 文生图 prompt/结果互送  
- Header 统一任务条、混合时间线  
- 再调全局 design token  
- 登录页鼠标跟随光斑/粒子系统  
- 强制改文生文 `EXAMPLE_PROMPTS` 的 emoji（未在本轮需求内；可后续一并清理）

## 1. 登录页 — 分屏工坊（方案 A）

### 1.1 桌面（`md` 及以上，建议断点 `768px`）

```
┌──────────────────────────┬─────────────────────────┐
│ 左 · 品牌舞台（约 45–50%） │ 右 · 凭证区（约 50–55%）   │
│ 固定深焙深色气质           │ 跟随主题 surface          │
│ 「焙」字标 + 深焙          │ 登录 | 注册 segmented     │
│ Deep Roast 小标           │ 用户名 / 密码             │
│ 1–2 行品牌短文案           │ 主按钮实心 accent         │
│ 可选 2–3 条微卖点（纯文字） │ 忘记密码 → 联系管理员      │
│ glow-spot / 细 grain      │ AdminContactModal 不变    │
└──────────────────────────┴─────────────────────────┘
```

- 左栏即使用户全局为 light theme，**登录左栏仍可用深色 Atelier 底**（「进门入炉」），右栏用当前主题变量。  
- 字标复用现有「焙」方标 + `font-display`（Fraunces），与主应用 Header 一致。  
- **禁止**大号 ☕ emoji 作为主视觉。  

### 1.2 窄屏（表单优先）

- **隐藏左栏**  
- 顶部：小「焙」+「深焙」一行  
- 下方：完整登录/注册表单（与现逻辑相同）  
- 避免双栏挤压或勉强保留分屏  

### 1.3 行为（不得破坏）

| 行为 | 保持 |
|------|------|
| 登录 | `login(username, password)` → success 则 `window.location.href = "/"` |
| 注册 | `register(...)` 同上 |
| 校验 | 空用户名/密码本地错误文案 |
| 错误 | 表单上方错误条 |
| 联系管理员 | 仅 login tab；`AdminContactModal` + `/api/public/admin-contact` |
| Tab | login / register 切换清空 error |

### 1.4 动效（轻）

- 右栏（或整卡）`animate-fade-up` 入场即可  
- 左栏文案可极轻 stagger（CSS only，可选）  
- **不要**依赖额外动画库或 canvas  

### 1.5 文件

- 主要改：`src/app/login/page.tsx`  
- 样式：优先复用 `globals.css` 已有 token / `font-display`；若需登录专用类可加极少 utility，避免新主题体系

## 2. 文生图去 Emoji

### 2.1 替换清单

| 位置 | 现状 | 目标 |
|------|------|------|
| `ImageInputColumn` 工具前缀 | `🔧` | 删除，或纯文字「工具」且不抢眼 |
| 反推按钮 | `📷 反推` | `反推提示词`（或保持短文案「反推」） |
| 图生图按钮 | `🖼️ 图生图` | `图生图` |
| `IMAGE_STYLE_PRESETS` | icon + label | **仅 label**；从类型/数据中移除 `icon` 字段 |

预设标签保持：无预设 / 写实摄影 / 日系动漫 / 油画艺术 / 电影级；`prompt` 字符串不变。

### 2.2 行为

- 点击预设仍 `setPrompt(preset.prompt)`（「无预设」清空）  
- 反推 / 图生图 panel 开合逻辑不变  
- 生成、积分、尺寸选择不变  

### 2.3 文件

- `src/types/index.ts` — `IMAGE_STYLE_PRESETS`  
- `src/components/ImageGen/ImageInputColumn.tsx` — 渲染  

不强制改 `EXAMPLE_PROMPTS`（文生文）。

## 4. 验收

- [ ] 桌面登录为左叙事 + 右表单；品牌无大号咖啡 emoji  
- [ ] 窄屏仅表单 + 顶栏字标，可登录/注册  
- [ ] 错误态、联系管理员弹层仍可用  
- [ ] 文生图工具栏与风格 chip 无 emoji；生成与预设仍可用  
- [ ] 不改 API 契约；`tsc` / 现有 build 可通过  

## 5. 风险

| 风险 | 缓解 |
|------|------|
| 左栏固定深色在 light 下「跳戏」 | 有意为之的入口仪式感；右栏跟主题即可 |
| 文案过长挤窄右栏 | 微卖点最多 3 条短句；表单区 min-width 合理 |
| 漏改其它 emoji | 本轮范围仅登录 + 文生图列表示位置；grep 验收 |
