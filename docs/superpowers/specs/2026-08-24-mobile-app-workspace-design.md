# 深焙移动端应用化工作台设计

## 目标

在不改动桌面端、管理后台、接口、数据结构或部署环境的前提下，将 `<= 767px` 的网页端调整为更接近原生 AI 应用的移动体验：界面紧凑、工作区沉浸、操作始终可达，并保留深焙现有的暖石色与焦糖强调色。

## 范围与约束

- 仅修改移动端呈现与交互；桌面端和管理后台保持原样。
- 不修改后端 API、积分规则、图像生成/编辑/反推的业务逻辑与数据契约。
- 不部署到服务器；所有预览和验证均在本机完成。
- 复用现有 Next/React/Tailwind/PWA 架构，不迁移到 UniApp。
- 沿用既有主题 CSS token，避免使用与当前产品不一致的纯黑白 ChatGPT 视觉。

## 信息架构

### 顶部栏

移动端使用紧凑固定顶部栏：

- 左侧为菜单按钮，用于次级导航。
- 中间展示当前工作区标题（生图、图库或对话）。
- 右侧保留积分余额入口和账户入口。

### 主工作区导航

在主内容区提供常驻、易触达的三项切换：`生图`、`图库`、`对话`。

这三项是高频工作区，不再要求用户每次从抽屉菜单中寻找。切换应维持当前已有的页面状态，避免不必要的重新加载。

### 菜单抽屉

菜单抽屉承载低频和账户类入口：公告、主题、账户相关项等。

抽屉顶部新增签到状态卡：

- 未签到：显示“今日签到 · +X 积分”，点击沿用现有签到动作。
- 已签到：显示“今日已签到”，不可重复触发。
- 积分余额仍由右上钱包入口查看；签到卡不替代积分明细。

## 核心工作流

### 生图

- 保留现有底部固定提示词输入区和生成按钮。
- 保留“反推”“图生图”“比例”等快捷工具。
- 点击“反推”或“图生图”继续以底部抽屉展开完整面板，而不是缩减功能。
- 图生图必须继续支持现有的多图、参考图、逐图提示词、风格、尺寸、批量数量、生成/停止与清空等能力。

### 图库

- 图库作为主工作区之一，保持现有查看和回用生成结果的流程。
- 为移动触控优化卡片间距、操作命中区和安全区留白。

### 对话

- 对话输入区保持固定在底部并遵守键盘安全区。
- 复制、重新生成等消息操作在移动端应可见或通过明确的点击入口获得，不依赖鼠标悬停。
- 减少首次进入时不必要的自动聚焦，避免页面一打开就弹出键盘。

## 视觉与交互原则

- 使用当前的浅石色页面底、纸张式表面层和焦糖色主操作，不引入 ChatGPT 的黑白默认配色。
- 主操作高度和点击区按触摸设备优化，控制信息密度但不牺牲工具可发现性。
- 底部抽屉应具有明确的标题、关闭入口和滚动边界；打开时背景不可误触，关闭后恢复原工作区状态。
- 兼容 iOS Safari 与 Android 浏览器的底部安全区、虚拟键盘和 16px 输入字体要求。

## 视觉参考修订（已确认）

以用户提供的“暖纸张图生图两步工作流”稿为移动端视觉验收参考。实现必须对齐其信息层级、留白、圆角、焦糖主按钮和底部 Tab 的应用化结构，而不是把桌面/旧版表单直接放进底部抽屉。

### 既有业务映射

- `生图`：承载现有文生图、图生图与反推能力；不新建“灵感”页。
- `对话`：承载现有 AI 对话和会话历史。
- `作品`：承载现有图库/图片历史。
- `我的`：承载现有钱包、账户、签到、公告、主题和退出相关入口；不新增账户业务。

### 图生图移动端结构

1. 顶部仅保留紧凑应用栏（菜单、居中品牌、已有公告/帮助入口），下方显示当前工具名称。
2. 底部常驻四项导航为 `生图 / 对话 / 作品 / 我的`；不再使用页面顶部的三段式导航，也不在菜单内重复这些主工作区。
3. 图生图使用完整两步式工作流：
   - 第一步“参考素材”：横向素材卡、清晰的目标图/参考图标识、添加素材卡、数量与用途提示。
   - 第二步“修改任务”：分别修改/参考修改模式切换、目标与参考图摘要、修改描述、更多设置和固定生成按钮。
4. “更多设置”使用卡片化展开面板，复用已有风格、主色、纹理、画幅比例和生成数量数据；画幅比例和数量改为触控芯片，禁止继续显示浏览器原生下拉菜单。
5. 反推同样使用紧凑、完整的上传与结果工作流，不得出现大面积无用途空白。

### 非目标

- 不新增灵感流、风格素材库后端、社交、收藏、额外账户体系或新的 AI 业务。
- 不改变图生图请求、反推请求、积分扣减、签到、图库、对话或账户 API。

## 实施边界

预计涉及的移动端组件包括：顶栏、移动菜单抽屉、图像工作区、图像移动输入栏、聊天消息操作与聊天输入行为，以及必要的移动端样式。

不会修改邀请码、签到接口、积分配置、图像 API、管理面板或服务器配置。

## 验收标准

1. 在 375px、390px 和 430px 宽度下，顶部、主导航、内容区和底部输入区均无横向溢出。
2. 生图、图库、对话均可直接在移动端主界面切换。
3. 菜单中可看到正确的签到状态；点击未签到状态能调用现有签到流程，已签到状态不可重复提交。
4. 图生图与反推完整面板仍可从生图页打开，并保留现有功能。
5. 软键盘弹出时，对话和生图输入不会被遮挡；抽屉能正常关闭。
6. 桌面端和管理后台的结构、样式、路由与业务逻辑不发生变化。
7. 仅在本机启动和验证，不执行任何生产部署。
