# 公告微信群二维码设计

## 目标

为站点公告增加可选的单张微信群二维码图片，帮助用户加入微信群，同时保持公告列表在手机端紧凑、稳定。

## 方案

- 管理员发布公告时可选择一张 PNG、JPEG 或 WebP 图片，大小不超过 2MB。
- 公告正文仍为必填，图片为可选；图片保存到站点的公开上传目录，数据库只保存图片 URL。
- 用户端公告列表只在公告含图片时显示“查看微信群二维码”与小箭头，默认收起；点击后展开图片。
- 图片使用 `max-width: 100%` 和固定的最大高度约束，保证窄屏不横向撑开；使用原生图片长按保存能力。
- 删除公告时同步删除对应图片文件；上传失败不会创建半成品公告。

## 接口与数据

`announcements` 增加可空的 `image_path` 字段。管理员 POST 接口改为接收 multipart/form-data：`body` 文本字段和可选 `image` 文件字段。列表接口返回 `imageUrl`，兼容没有图片的旧公告。

## 验证

测试覆盖图片格式/大小校验、multipart 上传契约、删除清理、管理员上传控件，以及用户端折叠展开和响应式图片展示。完成后运行项目测试、生产构建，并在服务器上执行数据库迁移和服务健康检查。
