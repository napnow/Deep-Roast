# 登录页「开始使用」按钮视觉优化设计

日期：2026-09-14

## 目标

让登录页首屏的「开始使用」入口更克制、更精致，与 `Deep Roast` 的暖深棕、编辑感品牌气质一致，同时保持入口清晰可用。

## 方案

采用已确认的 A「暖白细描边」方案：

- 将现有实心焦糖色胶囊改为透明底、暖白细描边胶囊。
- 按钮高度约 44px，减少纵向厚重感；文字与箭头处于同一视觉层级。
- 移除箭头后的独立圆形底，不新增图形或文案。
- 默认状态使用暖白文字与低对比描边，配合非常轻的内外高光。
- 悬停时描边和文字轻微转暖，背景仅增加低透明焦糖色；箭头向右移动约 3px。
- 按下时保留轻微缩放反馈；键盘焦点显示清晰的焦糖色焦点环。
- 保留现有磁吸包装、点击切换登录表单、入场动画和 reduced-motion 行为。

## 响应式与无障碍

- 桌面与移动端使用同一视觉语言，触控区域不小于 44px 高。
- 链接文字和箭头保持当前语义；装饰箭头继续对辅助技术隐藏。
- `:focus-visible` 必须清晰，但不在鼠标点击后持续显示。

## 实现边界

- 仅修改登录页 CTA 的样式和必要的 class 结构。
- 不调整标题、标语、背景、登录表单、动画时序或业务逻辑。
- 不引入新依赖或图片资源。

## 验收标准

- 默认状态不再出现实心橙色大色块或独立圆形箭头。
- 按钮视觉高度约 44px，暖白描边清晰且不过亮。
- hover、active、focus-visible 均有可辨识反馈。
- 点击仍正常进入登录/注册表单。
- reduced-motion、移动端与桌面端回归测试通过。
