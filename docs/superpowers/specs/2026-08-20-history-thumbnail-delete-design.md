# 历史缩略图快捷删除设计

## 目标

用户无需进入图片详情，即可直接从右侧“历史”素材网格删除图片，同时避免误触并保留现有选择、预览与详情操作。

## 交互

- 每个历史缩略图改为独立容器：主体按钮负责选择图片，右上角垃圾桶按钮负责删除。
- 桌面端删除按钮在缩略图悬停或键盘聚焦时显示；触屏设备始终显示。
- 删除按钮带明确的 `aria-label`，点击不会触发图片选择。
- 点击删除后继续使用当前确认文案“确认删除这张图片？”。确认后调用现有 `onDelete(image.id)`，取消则不改变任何状态。
- 若删除的是当前选中图片，沿用页面现有逻辑清空选中状态；其他图片不受影响。

## 视觉

- 按钮位于缩略图右上角，使用现有垃圾桶 SVG 图标。
- 默认采用半透明深色背景；悬停时转为危险色表面，不使用常驻红色叉号。
- 按钮点击热区不小于 30×30px，且不遮挡缩略图主要内容。

## 范围

- 修改 `AssetInspector` 的历史网格结构与对应 CSS。
- 不增加批量删除、撤销、长按菜单或后端接口；继续复用现有删除 API 和确认流程。

## 验证

- 缩略图主体仍可选择图片。
- 删除按钮不会触发选择。
- 确认与取消路径正确，删除当前图片后结果状态正确。
- 键盘可聚焦删除按钮，移动端按钮可见。
- TypeScript、定向 ESLint、测试与生产构建通过。
