# 管理端图片详情完整展示设计

## 目标

修复管理端查看图片时图片下半部分被裁切的问题，确保不同宽高比的图片都能完整查看，同时保留 Prompt、模型、尺寸、生成时间和关闭操作。

## 已确认方案

详情弹窗整体作为可滚动容器，图片区域不再参与固定高度的 `flex` 压缩，也不使用会隐藏溢出内容的布局。图片使用原始比例和 `object-contain` 约束在可视宽度内；当图片或信息内容超过视口高度时，由弹窗整体上下滚动。

## 交互与兼容性

- 图片完整展示，不裁剪、不变形。
- 桌面端和窄屏端都能通过弹窗滚动查看图片及详情。
- 点击遮罩关闭，点击弹窗内容不关闭。
- 不改变图片 URL、历史记录、Prompt 复制和删除等现有行为。

## 实现与验证

- 修改 `AdminImageDetailModal` 的容器滚动和媒体布局。
- 增加回归测试，确保媒体区使用完整展示策略且不再由 `overflow-hidden` 裁剪图片。
- 运行相关测试、全量测试、TypeScript 和 ESLint。
- 构建并部署到服务器，检查服务状态与公网管理端入口。
