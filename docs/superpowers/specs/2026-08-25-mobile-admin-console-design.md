# 手机端完整管理员控制台设计

## 目标

让管理员在手机端可完成现有全部管理操作，复用现有认证、接口与数据模型；普通用户不可见管理员入口且仍会受到服务端权限保护。桌面端后台布局保持不变。

## 已确认范围

- 手机端侧边栏仅管理员显示“模型配置”和“管理控制台”。
- “模型配置”直接复用已有设置弹窗：渠道、Base URL、API Key、对话与生图模型、启用状态、默认模型及模型目录获取均可操作。
- “管理控制台”进入既有 `/admin`，覆盖运营总览、站点设置与内容、AI 风格、用户选择与详情、图片、对话、积分、用户 API Key、重置密码、封禁与删除。

## 架构

不创建第二套后台。移动侧栏扩展管理员专属回调，页面继续由现有 `AppModals` 承载模型设置弹窗。`/admin` 继续使用现有角色校验与 API；仅在窄屏重排其界面：左侧常驻栏转换为顶部管理栏，模块与用户选择改为可展开的全屏抽屉，主内容改为单列滚动。

## 手机端交互

1. 管理员从工作台左上角侧边栏进入“模型配置”或“管理控制台”。
2. 管理台顶部提供返回工作台、当前模块和“用户”入口。
3. 总览、站点与内容、AI 能力、用户以横向模块切换呈现。
4. 点击“用户”打开全屏用户选择抽屉；选择用户后回到主内容展示完整详情与原有操作。
5. 长表格仅其自身横向滚动；页面、抽屉和弹窗各自管理滚动边界。
6. 现有封禁、删除和密码重置确认逻辑不变。

## 约束与验收

- 不新增后端接口或权限模型，不复制模型配置逻辑。
- 非管理员看不到两个入口；手动访问 `/admin` 仍按现有逻辑返回工作台。
- 375px 宽度下每项后台功能可访问和操作，无整个页面横向溢出。
- 桌面端 `admin-rail` 及工作台桌面 UI 不变化。
- 增加管理员入口、移动后台模块/用户抽屉与桌面隔离的契约测试；运行 TypeScript 与相关测试。
