# 产品需求文档（PRD）· 深焙 Deep Roast

> 自托管文生文 / 文生图工作台。本文描述产品目标与范围，实现细节以代码与 `docs/architecture.md`、`docs/api.md` 为准。

## 1. 背景与目标

- **定位**: 个人或小团队自托管的 AI 工作台，强调可控上游（自配 OpenAI 兼容 Base URL / Key），而非绑定单一商业中转。
- **品牌语气**: 深焙 / Atelier — 深度思考、慢焙出好答案；UI 偏石色炭黑、克制强调色。
- **成功标准**: 本地 `npm run dev` 可完成注册登录、对话、生图、设置上游、管理用户与积分。

## 2. 用户与场景

| 角色 | 能力 |
|------|------|
| 访客 | 登录 / 注册；查看公开管理员联系方式 |
| 普通用户 | 对话、生图、每日签到、积分消费、改密、查看钱包 |
| 管理员 | 用户封禁/删除与积分、内容审计、注册开关、公告、站点联系方式、重置密码、全局 LLM 配置 |

## 3. 功能范围

### 3.1 文生文

- 多会话、流式输出、历史持久化
- 可切换已启用的文本模型

### 3.2 文生图

- 文生图、风格预设（**无 emoji 依赖**的标签样式）、历史面板
- 图生图、反推提示词（依赖上游 vision / 多模态能力）
- **图推模型可配置**：设置页从 API 模型目录点选（与文/图同一套 Base URL + Key）；未单独配置时回落文生文模型
- 生成文件落盘 `public/images/`（gitignore，不进仓库）

### 3.3 账号与安全

- Cookie JWT 登录
- 用户自行改密；管理员可重置他人密码
- 生产强制 `JWT_SECRET`
- API Key 仅存服务端；前端配置接口返回 mask / hint

### 3.4 积分

- 注册赠送；普通用户按北京时间每日签到 +50；生图 5 积分/张（管理员免费）
- 管理员发放/扣减、流水可查；模拟充值已下线
- 积分不足时引导签到或联系管理员

### 3.5 管理与站点

- 用户列表、软封禁/解封、硬删除（级联历史）、内容查看
- **管理后台可开关注册**（无需改代码）；站点公告（登录页公开列表 + 站内铃铛、未读红点）
- 登录页管理员联系文字 + 可选二维码图

## 4. 非功能需求

### 4.1 性能

- SSE 流式，体感首 token 取决于上游
- 图片生成等待由上游决定；本地只做落盘与记录

### 4.2 安全

- API Key 存 PostgreSQL；列表接口 mask（例如 `sk-a****wxyz`）
- 浏览器不直连上游 Key
- 生成图 / 上传图不进入 git
- 开源发行不包含真实 `.env`、不硬编码第三方中转 URL

### 4.3 兼容性

- 现代浏览器（Chrome / Firefox / Edge 近两年版本）
- Node.js ≥ 18（推荐 20）
- PostgreSQL ≥ 14

### 4.4 可靠性

- 部分模型路径可配置重试（如 grok 生图）
- 上游 429 / 5xx 返回可读错误信息
- 数据库或配置缺失时给出明确提示

## 5. 明确不在当前开源默认范围内

- 多租户隔离的企业级权限模型
- 内置付费支付通道
- 硬编码某一家中转站账号或默认 Base URL
- 保证某一上游模型的可用性或定价

## 6. 主流程（摘要）

```
安装 → 配置 DATABASE_URL / JWT_SECRET → migrate → seed
  → 登录 admin → 设置 Base URL + Key → 启用模型
  → 文生文 / 文生图 →（可选）管理用户与积分
```

文生图体验流：

```
[输入 prompt / 选风格] → [生成] → [结果可下载/复制 prompt]
  → [历史面板] → [可删除]
```
