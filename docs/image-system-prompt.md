# 文生图系统提示词

管理员可在 **设置** 中配置一段「图片生成系统提示词」。每次用户生图时，服务端会把它自动拼在用户输入前面：

```
{系统提示词}

{用户 prompt}
```

## 行为说明

| 情况 | 结果 |
|------|------|
| 提示词为空（默认） | 只发送用户原文，与未配置时一致 |
| 已填写 | 上游收到「系统提示词 + 空行 + 用户输入」 |
| 修改后 | 下一次生图立即生效（每次请求读库） |

- 配置入口：登录后 **设置** →「图片生成系统提示词」
- 持久化字段：`llm_config.image_system_prompt`
- 读写：`GET/PUT /api/config` 的 `imageSystemPrompt`
- 拼接逻辑：生图 API（`POST /api/image`）在调用上游前完成

历史记录、积分流水里一般保留**用户原始 prompt**，不把系统提示词写进用户可见文案（以实现代码为准）。

## 使用建议

- 写可复用的质量/风格约束（分辨率、光影、构图等），避免写死具体画面内容。
- 过长提示词可能触达上游 token/内容限制，请按所用模型自行控制长度。
- 该配置为**全站共享**（当前为单行全局 LLM 配置），所有用户生图都会带上。
